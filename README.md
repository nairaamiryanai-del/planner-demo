# Planner — личный планировщик на все случаи жизни

Персональный планировщик-дашборд в виде PWA: задачи, календарь, фриланс-заказы, расписание детей, поездки, покупки, заметки, цели, напоминания и здоровье в одном приложении. Работает в браузере и ставится на телефон как приложение.

Проект сделан методом вайб-кодинга: весь код написан в паре с ИИ (Claude Code), от идеи до публикации.

> Это демо-копия: в каждом разделе лежат примеры, чтобы было видно, как всё работает. Личных данных в репозитории нет.

## Что умеет

| Раздел | Возможности |
|---|---|
| **Дашборд** | Сводка дня: активные задачи, проекты, цели, приём лекарств; ближайшие дедлайны, напоминания на 7 дней, поездки, прогресс задач |
| **Задачи** | Канбан «Запланировано / В работе / Сделано», приоритеты, категории, теги, дедлайны, перетаскивание |
| **Календарь** | Все события в одной сетке месяца: задачи, напоминания (с повторами), дедлайны проектов, цели, занятия детей, поездки |
| **Проекты** | Трекер фриланс-заказов: единицы работы (посты, макеты) с датами сдачи, прогресс, оплата, архив |
| **Дети** | Недельное расписание кружков, быстрое добавление списком, календарь посещений и оплаты с итогами месяца |
| **Поездки** | Дела до поездки и список вещей по категориям с прогрессом сборов |
| **Покупки** | Списки покупок по категориям |
| **Заметки** | Текст и чек-листы, цвета, закрепление |
| **Цели** | Цели с шагами и прогрессом, сроки |
| **Напоминания** | Дата, время события и время уведомления, повторы (день, неделя, месяц, год) |
| **Здоровье** | Курсы лекарств по времени суток, серии и соблюдение, динамика за 30 дней, трекер воды, календарь цикла с прогнозом |

Плюс: глобальный поиск по всем разделам, резервная копия в JSON (скачать и восстановить), светлая тема, адаптивная вёрстка под телефон.

## Как это устроено

- **Фронтенд**: React 19 + Vite, react-router, date-fns, lucide-react. Данные хранятся в `localStorage` и живут в одном контексте (`src/context/PlannerContext.jsx`).
- **PWA**: `vite-plugin-pwa`, работает офлайн, плашка «Обновить» при выходе новой версии.
- **Синхронизация между устройствами со сквозным шифрованием**: пользователь придумывает кодовое слово, из него на устройстве выводятся идентификатор аккаунта и ключ AES-GCM (PBKDF2). В облако (Upstash Redis) уходит только зашифрованный блок, сервер не может прочитать данные (`src/lib/sync.js`, `api/sync.js`).
- **Push-уведомления «как будильник»**: Web Push (VAPID) и service worker. Расписание срабатываний хранится на сервере, «будильщик» `api/tick.js` вызывается внешним планировщиком каждые 5 минут, рассылает push и переносит повторяющиеся напоминания. Повторы считаются в часовом поясе пользователя.
- **Серверная часть**: Vercel Functions в папке `api/`.

```
src/
  components/   экраны разделов (TaskBoard, Health, ChildActivities, …)
  context/      PlannerContext: состояние, синхронизация, планирование уведомлений
  lib/          шифрование и синхронизация, push, расписание, даты
  data/         справочники и демо-данные
api/            серверные функции: sync, schedule, tick, push-subscribe, push-test
public/         иконки и обработчик push для service worker
```

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173: приложение сразу запустится в **демо-режиме** с примерами во всех разделах. Данные хранятся только в браузере, сервер не нужен.

Чтобы включить синхронизацию между устройствами и push-уведомления, нужен деплой на Vercel с Upstash Redis и VAPID-ключами и переменная `VITE_SYNC_ENABLED=true`. Полный список переменных в `.env.example`.
